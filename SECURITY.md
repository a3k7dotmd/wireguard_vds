# Политика безопасности

Если вы нашли уязвимость в скриптах — утечку приватных ключей, нарушение прав доступа, command injection через email-аргумент в `wgctl add` / `wgctl remove`, или любую другую — **пожалуйста, не открывайте публичный issue**.

Сообщите приватно через GitHub Security Advisories:

<https://github.com/blackden/wireguard_vds/security/advisories/new>

Канал доступен всем — он создаёт приватное обсуждение между вами и поддерживающими репозитория. Я постараюсь ответить в течение нескольких дней.

## Поддерживаемая ветка

Только `master`. Релизных тегов и старых веток не поддерживаем.
